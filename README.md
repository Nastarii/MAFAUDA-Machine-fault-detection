# MAFAUDA-Machine-fault-detection

Esse repositório contém a análise de detecção de falhas em máquinas por meio de uma classificação binária das classes de operações normais e desbalanceamento. O modelo utiliza redes neurais para séries temporais a fim de identificar padrões e prever anomalias no funcionamento dos equipamentos.

Para acessar as análises realizadas, é necessário abrir o arquivo .ipynb, que contém todos os passos do processamento, modelagem e explicações. As análises podem ser executadas diretamente na IDE Google Colab, permitindo a reprodução e modificação do código sem a necessidade de configurações locais.
